Guia rápido para apresentar

Quatro conceitos para guardar.

Uma explicação curta de cada termo e referências oficiais para se preparar melhor.

Teste unitário
Verifica uma unidade pequena de comportamento, isolada de dependências externas como o banco.
Suíte
Grupo de testes relacionado, executado e reportado como conjunto.
Mock / double
Substituto controlado de uma dependência. Útil para simular respostas; não prova o comportamento do sistema substituído.
Cobertura
Indica quanto do código instrumentado foi exercitado; percentual alto não garante ausência de defeitos.
